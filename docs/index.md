# CRM Interface Switcher

A free, open-source browser extension that allows you to switch between Salesforce Classic and Lightning Experience with a single click.

## Features

- One-click interface switching.
- Automatic detection of Classic and Lightning Experience.
- Lightning Setup domain support.
- Compact draggable floating dock.
- Hover enlargement.
- Locally saved dock position.
- Browser toolbar popup.
- No OAuth or separate authentication required.
- No analytics or tracking.

## Compatibility

Designed for Google Chrome and Microsoft Edge.

Supported Salesforce domain patterns:

- *.my.salesforce.com
- *.lightning.force.com
- *.my.salesforce-setup.com

Production, Sandbox, Developer Edition and Trailhead domain formats are supported by the domain detection logic.

## Privacy and security

CRM Interface Switcher uses your existing authenticated Salesforce session without collecting credentials or session tokens.

The extension processes page URLs locally and stores only the numeric dock position.
