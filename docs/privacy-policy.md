# Privacy policy — CRM Interface Switcher
Effective 24 November 2026. Maintainer: Vinod M E.

The extension processes the active page URL locally to identify supported Salesforce interfaces and construct a same-org navigation destination. The popup displays its hostname. The extension stores only a numeric dock position in chrome.storage.local; it is retained until removed/reset by the browser or extension storage is cleared. No developer-operated server, telemetry, analytics, advertising, sale or sharing of user data is implemented. The extension does not read passwords, session cookies or business records. Ordinary browser navigation communicates with Salesforce, whose own privacy practices apply. Browser/store services may process data independently.

Permissions: activeTab supports popup detection and navigation; storage retains dock position; matching HTTPS content scripts display the dock on supported pages. Removal of the extension normally removes its local storage; browser behavior may vary. No developer-held user data exists to request deletion of. Support requests submitted voluntarily to public GitHub Issues are governed by GitHub's policies; do not include private information.

Policy updates will be published here. Contact: https://github.com/vinod4658/crm-interface-switcher/issues.
